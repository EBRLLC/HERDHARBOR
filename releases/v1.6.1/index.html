HerdHarbor Alpha v1.6.1

One current release for farm analytics, complete domestic rabbit genetics, pedigrees, breeding intelligence, Shows, production, health, and optional standards and multi-species resources.

Farm analytics

  • Whole-farm, species, and date-range filters.
  • Overview, breeding, births, sales, revenue, expenses, and feed summaries.
  • Growth and weight charts based on recorded measurements.
  • Shows, production, and health-measurement analytics when relevant data exists.

Complete rabbit genetics

  • Deterministic A/B/C/D/E, En spotting, and Vienna inheritance.
  • Exact results only when genetics are resolved; uncertainty remains visible as ranges.
  • Phenotype, pedigree, offspring, and breeder-entered evidence stay distinct.
  • Genetics profiles, Pair Analysis, pedigrees, carrier summaries, and prediction snapshots.

Standards & multi-species resources

  • Optional structured rabbit breed-standard and judging references.
  • Genetically possible outcomes remain separate from breed recognition.
  • Species-aware genetics guidance for supported livestock records.
  • Optional reference failures never block core farm records.

Connected farm records

  • Shows, awards, exhibitors, and optional 4-H/FFA projects.
  • Production, health, finance, customers, sales, tasks, and transfers.
  • Protected cloud sync, offline recovery, backups, and Excel tools.
  • Existing accounts and farm records remain compatible.

Current application build

  • Website, app shell, offline cache, monitoring, and manifests identify v1.6.1.
  • Android version name 1.6.1 with version code 10.
  • Superseded executable copies were removed from the active application.
  • Historical release notes and database migrations remain available.

Help & account resources

  • Expanded How-To Center for common HerdHarbor workflows.
  • Direct links to Support, Privacy, Terms, and account deletion.
  • Clear breeding-planning and management-estimate limitations.
  • In-app feedback remains available during Alpha testing.
Data safety: v1.6.1 preserves existing accounts, local and cloud farm records, backups, storage compatibility, and database migration history.
