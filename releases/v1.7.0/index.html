Current Alpha release

HerdHarbor Alpha v1.7.0

Optional ARBA Standards & Judging is now part of HerdHarbor, adding structured rabbit standards references, breeder-facing evaluation, richer Shows records, and standards-aware breeding insights without requiring ARBA workflows.

ARBA standards registry

  • Structured reference for 53 recognized rabbit breeds.
  • Recognized/public variety references and working-standard entries remain separate.
  • 4-class and 6-class structures and public weight information are included where verified.
  • Unknown or incomplete rules are left unresolved instead of guessed.

Standards browser

  • Browse Rabbit → Breed → Variety without leaving HerdHarbor.
  • Review class structure, public weight references, variety status, physical-characteristic summaries, and breed considerations.
  • Search structured breeder references inside the app.
  • Current Standard of Perfection remains the controlling reference.

Evaluate Against Standard

  • Use recorded age, sex, latest weight, variety/color, supported measurements, and breeder-recorded concerns.
  • See weight status, age-class eligibility, variety status, possible faults or disqualifications, and missing measurements.
  • Saved evaluations become part of the animal’s HerdHarbor history.
  • Every result is labeled as an informational breeder tool.

Judging & Shows integration

  • Reference judging terminology, faults, disqualifications, show classifications, and breed considerations.
  • Existing Shows workflows remain intact.
  • Optional fields cover standard edition, variety/group, standards observations, leg, points, BOV, BOSV, BOB, BOSB, Best in Show, and Reserve in Show.
  • Judge, class, placement, comments, notes, and awards continue to use the existing Show records.

Genetics + standards intelligence

  • Pairing context can combine genetics, pedigree evidence, show history, and saved standards evaluations.
  • Repeated weight-at-maturity or standards observations can be surfaced alongside genetic compatibility.
  • Evidence sources remain distinct rather than being collapsed into an unsupported composite score.
  • Genetic possibility remains separate from recognized showroom variety status.

Optional by design

  • ARBA tools default off.
  • General animal records, pedigrees, breeding/genetics, health, Analytics, sales, production, finance, and Shows continue independently.
  • Proprietary Standard of Perfection prose and complete point schedules are not reproduced.
  • HerdHarbor does not claim to replace an ARBA judge, registrar, show rules, or the current Standard of Perfection.

Current application build

  • App version 1.7.0 with build ID arba-standards-1.
  • Android version name 1.7.0 with version code 13.
  • The PWA cache was refreshed so installed users receive the new release assets.
  • The v1.7.0 Standards registry, UI, and CSS are included in offline/network-first delivery.

Everything from prior releases

  • Farm analytics and growth/weight charts.
  • Complete domestic rabbit genetics and pedigree evidence.
  • Shows, production, health, finance, customers, sales, tasks, and transfers.
  • Protected cloud sync, backups, offline recovery, and Excel tools.
Important standards note: HerdHarbor’s Standards tools are informational breeder references. When an exact rule is not verified in the bundled structured data, HerdHarbor directs the breeder to the current ARBA Standard of Perfection instead of inventing a result.
