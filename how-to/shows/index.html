Shows How-To

Use Shows to track competitions, classes, placements, awards, judge feedback, exhibitors, animal show history, optional projects, Kentucky 4-H rabbit guidance, FFA/local youth-show rule profiles, and showmanship practice while keeping animals, Finance, Health, and cloud records in one HerdHarbor workspace.

Shows

Add and manage a show

  1. Open Shows. In HerdHarbor, choose Shows from the main navigation.
  2. Select Add Show. Enter the show name, type, organization, start/end date, and location.
  3. Use a custom show type when needed. County fairs, 4-H, FFA, ARBA, breed clubs, livestock shows, open shows, youth shows, and custom types are supported.
  4. Add notes or attachments. Premium books, flyers, class sheets, or other supporting files can stay with the show record.
  5. Archive when the show is over. Archiving preserves entries, results, awards, finance links, and historical reporting.

Exhibitors

Add exhibitors

  1. Open the Exhibitors tab inside Shows.
  2. Add each exhibitor who needs their own history. Multiple family members can be tracked under the same HerdHarbor account.
  3. Use the same exhibitor on future entries. HerdHarbor builds a private achievement history across shows, years, species, animals, and organizations.
Privacy: Exhibitor achievement history is part of your private HerdHarbor workspace. It is not a public leaderboard.

Entries

Enter an animal in a class

  1. Open the show record.
  2. Add an entry. Choose an existing HerdHarbor animal and an exhibitor.
  3. Enter class information. Add class name, division, class number/count where applicable, entry number, show weight, condition, and project link if relevant.
  4. Add more than one class when needed. The same animal can have multiple entries/classes at one show when the event rules allow it.
No duplicate animal record: Shows links to the animal already in HerdHarbor. It does not create a second show-only copy of that animal.

Results & Awards

Record placements, judge feedback, and awards

  1. Open the correct entry.
  2. Add a result. Choose 1st–10th, enter a higher numeric placement, or use a custom placement.
  3. Add judge information. Record judge name, score, comments, strengths, and improvement notes when available.
  4. Add awards separately. Multiple awards can be tied to the same entry/result, including Champion, Reserve, Best of Breed, Best in Show, ribbons, class wins, and custom awards.
  5. Edit mistakes without losing history. Result and award records can be corrected while preserving the show relationship.

New in v1.7.0

Open Youth Guides inside Shows

  1. Open Shows.
  2. Choose Youth Guides. HerdHarbor adds the guide beside the existing Overview, Shows & Results, Exhibitors, Projects, and Reports tabs.
  3. Choose Kentucky 4-H, FFA / Local Shows, or Showmanship Practice.
  4. Use the guide as preparation support. HerdHarbor summarizes public information in its own wording and links directly to the official source.
  5. Always follow the current event rulebook. Fair dates, deadlines, health requirements, eligibility, entry limits, and class rules can change.

Kentucky 4-H

Use the Kentucky 4-H Rabbit Show Guide

The built-in guide is based on the publicly posted 2025 Kentucky State Fair 4-H Rabbit Division material. It is designed to make the useful requirements easy to see without reproducing an entire fair document.

  1. Confirm electronic entry and deadline requirements. The referenced State Fair guide requires electronic entries and does not permit day-of-show entries.
  2. Match the permanent left-ear tattoo to the entry. Breed and tattoo information are part of the referenced entry requirements.
  3. Review health and travel-cage preparation. HerdHarbor summarizes the public health, ventilation, waste-control, and safe-travel expectations from the guide.
  4. Confirm the exact rabbit and class. The referenced guide does not permit substitutions of rabbits after registration.
  5. Prepare the exhibitor for the show table. The youth exhibitor is responsible for moving the rabbit to and from the table and following show order.
  6. Review showmanship and awards. The guide references Junior and Senior Showmanship, breed awards, Best 4-Class, Best 6-Class, Best in Show, and Reserve Best in Show.
Important: The official Kentucky State Fair guide, current fair premium book, and county Extension instructions control. HerdHarbor is a preparation reference, not the event authority.

FFA / Local Youth Shows

Save the actual show rules instead of assuming one national standard

FFA rabbit-show requirements are normally controlled by the fair, state association, chapter, or local event. HerdHarbor therefore uses a configurable local-show profile rather than inventing a universal FFA rabbit rulebook.

  1. Open Youth Guides → FFA / Local Shows.
  2. Create a profile for the actual event. Name the fair/show and add the organization and state.
  3. Paste the official rules link. Keep the current premium book or event rules one tap away.
  4. Add eligibility notes. Record membership, residency, age, ownership-date, or other local requirements.
  5. Add class and showmanship notes. Save combined-class rules, entry limits, divisions, dress requirements, or local scorecard details.
  6. Set the date you verified the rules. That makes it obvious when a profile needs to be checked for the next show season.
Kentucky FFA publishes State Fair exhibit and livestock rule links. ARBA fair-show rules also recognize that fairs may apply 4-H/FFA membership restrictions and may combine classes under fair rules.

Showmanship Practice

Practice handling and knowledge before the event

  1. Practice safe transport and calm handling.
  2. Practice correctly posing the rabbit.
  3. Know the rabbit’s breed, variety/color, sex, age class, tattoo, and basic breed purpose.
  4. Practice identifying body parts, fur type, condition, feet, teeth, eyes, ears, and obvious health concerns.
  5. Use correct terminology and explain what you are checking.
  6. Practice questions about feed, water, grooming, housing, health observation, and project records.
Showmanship evaluates the exhibitor’s handling and knowledge, not simply which rabbit is the best specimen. HerdHarbor’s checklist is a practice aid and not an official scorecard.

History

Review animal and exhibitor history

Animal Show History summarizes shows entered, classes, first places, awards, and championship-level achievements. Exhibitor Achievement History can be filtered by year, species, animal, organization, and show type.

Archived or inactive animals remain available in historical show records so old results do not disappear when an animal is sold, deceased, or retired.

4-H / FFA Projects

Create a project inside Shows

  1. Open Projects inside Shows.
  2. Create the project. Choose year, project name/type, exhibitor, and an existing HerdHarbor animal.
  3. Add goals and notes. Track milestones, progress, training, care notes, or project work.
  4. Add progress photos. Beginning, progress, animal, project-work, show, and award photos can be organized with the project.
  5. Track growth. Project growth and average daily gain use the animal’s existing HerdHarbor Weight records.
  6. Use existing Health records. Treatments, medications, vaccinations, observations, and veterinary visits remain in normal HerdHarbor Health history.
  7. Use existing Finance records. Feed, supplies, entry fees, premiums, and other project money remain normal HerdHarbor transactions with project/show links.
  8. Review the project timeline. HerdHarbor combines linked health, finance, shows, goals, notes, and photos into one chronological view.
Record-book note: The HerdHarbor Project Record is a farm/project summary and is not automatically an official county or state 4-H or FFA record book. Always follow the forms required by your local program.

Finance

How show and project money works

Shows does not have a separate budget. When you add an entry fee, travel cost, project supply, premium, sale-related income, or another show/project transaction, HerdHarbor stores it in the same Finance transaction list used everywhere else.

If you edit or delete the transaction in Finance, the Shows/project totals update because they are reading the same transaction record.
