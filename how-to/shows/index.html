Shows How-To

Use Shows to track competitions, classes, placements, awards, judge feedback, exhibitors, animal show history, and optional 4-H/FFA projects while keeping animals, Finance, Health, and cloud records in one HerdHarbor workspace.

Shows

Add and manage a show

  1. Open Shows. In HerdHarbor, choose Shows directly below Births & Litters.
  2. Select Add Show. Enter the show name, type, organization, start/end date, and location.
  3. Use a custom show type when needed. County fairs, 4-H, FFA, ARBA, breed clubs, livestock shows, open shows, youth shows, and custom types are supported.
  4. Add notes or attachments. Premium books, flyers, class sheets, or other supporting files can stay with the show record.
  5. Archive when the show is over. Archiving preserves entries, results, awards, finance links, and historical reporting.

Exhibitors

Add exhibitors

  1. Open the Exhibitors tab inside Shows.
  2. Add each exhibitor who needs their own history. Multiple family members can be tracked under the same HerdHarbor account.
  3. Use the same exhibitor on future entries. HerdHarbor builds a private achievement history across shows, years, species, animals, and organizations.
Privacy: Exhibitor achievement history is part of your private HerdHarbor workspace. It is not a public leaderboard.

Entries

Enter an animal in a class

  1. Open the show record.
  2. Add an entry. Choose an existing HerdHarbor animal and an exhibitor.
  3. Enter class information. Add class name, division, class number/count where applicable, entry number, show weight, condition, and project link if relevant.
  4. Add more than one class when needed. The same animal can have multiple entries/classes at one show.
No duplicate animal record: Shows links to the animal already in HerdHarbor. It does not create a second show-only copy of that animal.

Results & Awards

Record placements, judge feedback, and awards

  1. Open the correct entry.
  2. Add a result. Choose 1st–10th, enter a higher numeric placement, or use a custom placement.
  3. Add judge information. Record judge name, score, comments, strengths, and improvement notes when available.
  4. Add awards separately. Multiple awards can be tied to the same entry/result, including Champion, Reserve, Best of Breed, Best in Show, ribbons, class wins, and custom awards.
  5. Edit mistakes without losing history. Result and award records can be corrected while preserving the show relationship.

History

Review animal and exhibitor history

Animal Show History summarizes shows entered, classes, first places, awards, and championship-level achievements. Exhibitor Achievement History can be filtered by year, species, animal, organization, and show type.

Archived or inactive animals remain available in historical show records so old results do not disappear when an animal is sold, deceased, or retired.

4-H / FFA Projects

Create a project inside Shows

  1. Open Projects inside Shows.
  2. Create the project. Choose year, project name/type, exhibitor, and an existing HerdHarbor animal.
  3. Add goals and notes. Track milestones, progress, training, care notes, or project work.
  4. Add progress photos. Beginning, progress, animal, project-work, show, and award photos can be organized with the project.
  5. Track growth. Project growth and average daily gain use the animal’s existing HerdHarbor Weight records.
  6. Use existing Health records. Treatments, medications, vaccinations, observations, and veterinary visits remain in normal HerdHarbor Health history.
  7. Use existing Finance records. Feed, supplies, entry fees, premiums, and other project money remain normal HerdHarbor transactions with project/show links.
  8. Review the project timeline. HerdHarbor combines linked health, finance, shows, goals, notes, and photos into one chronological view.
Record-book note: The HerdHarbor Project Record is a farm/project summary and is not automatically an official county or state 4-H record book. Always follow the forms required by your local program.

Finance

How show and project money works

Shows does not have a separate budget. When you add an entry fee, travel cost, project supply, premium, sale-related income, or another show/project transaction, HerdHarbor stores it in the same Finance transaction list used everywhere else.

If you edit or delete the transaction in Finance, the Shows/project totals update because they are reading the same transaction record.

Reports

Print or save a report

Show & Awards Report

Use this for competition history by year, exhibitor, animal, species, organization, placement, award, and judge information.

HerdHarbor Project Record

Use this for project goals, growth, finance, health, notes, photos, and show activity. Choose Print / Save PDF from the report view when you need a portable copy.

Need more help?

Keep your records connected.

If something entered in Shows looks wrong in Finance, Health, or the animal record, check the linked canonical record first. HerdHarbor intentionally uses one source of truth so corrections flow through the rest of the app.
